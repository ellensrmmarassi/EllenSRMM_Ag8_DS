📊 Pesquisa de Satisfação — TudoWeb

Projeto desenvolvido em Python para realizar uma pesquisa de satisfação com 50 entrevistados.

🎯 Objetivo

O programa coleta:

Nome
Idade
Avaliação do atendimento

As opções são:

⭐ Excelente
👍 Bom
👎 Ruim

Ao final, o sistema apresenta o total de respostas de cada avaliação.

🐍 Conceitos utilizados
input() e print()
Variáveis e contadores
for
if, elif e else
Conversão de dados com int()
F-strings
🛠️ Tecnologias

Python + Visual Studio Code

Projeto desenvolvido como prática de lógica de programação e desenvolvimento de sistemas.
